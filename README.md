# sRAPID Prognostic Index for Pleural Infection

A mobile-friendly exploratory calculator based on the multivariable hazard ratios reported for the sRAPID model.

## What it reports

The calculator estimates the relative 3-month mortality hazard compared with a reference profile:

- Age: 50 years
- Urea: 5 mmol/L
- Albumin: 35 g/L
- Infection source: community-acquired

Reported model effects:

- Age: HR 1.06 per year
- Urea: HR 1.04 per mmol/L
- Albumin: HR 0.95 per g/L
- Hospital-acquired infection: HR 1.96

Development cohort: 1,344 patients; 153 deaths within 3 months; C-statistic 0.87.

## Important limitation

This tool estimates relative hazard, not absolute mortality probability. The model has undergone internal validation only and requires independent external validation. It is intended for research and educational use and should not be used as the sole basis for clinical decisions.
